Enunciado do problema: Nomeie os principais módulos utilizados na programação em Python para realizar operações matemáticas. Resolução: Os principais módulos para operações matemáticas em Python incluem o módulo 'math' e o módulo 'statistics'. O módulo 'math' fornece funções para operações matemáticas básicas como seno, cosseno, raiz quadrada, etc. Já o módulo 'statistics' oferece funções para calcular estatísticas como média, mediana, moda, etc. Conclusão: Ao nomear esses módulos, podemos identificar facilmente as ferramentas disponíveis para realizar operações matemáticas em Python, facilitando a seleção do módulo adequado para uma determinada tarefa.
