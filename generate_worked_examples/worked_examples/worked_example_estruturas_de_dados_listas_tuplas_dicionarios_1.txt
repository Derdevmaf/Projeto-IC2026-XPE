**Worked Example: Análise de Desempenho de Turma com Estruturas de Dados em Python**

**1. Enunciado do Problema/Tarefa:**

Você é um professor e possui um registro de notas de seus alunos em diferentes disciplinas. Sua tarefa é processar esses dados utilizando estruturas de dados em Python (listas, tuplas, dicionários) para:
a) Calcular a média individual de cada aluno.
b) Calcular a média de cada disciplina para toda a turma.
c) Identificar a disciplina com a maior média geral da turma.

Após realizar essas análises, **apresente uma conclusão sobre o desempenho geral da turma**, destacando as principais observações e explicando qual estrutura de dados foi mais adequada para representar e manipular cada parte da informação, justificando suas escolhas.

**2. Resolução Comentada, Passo a Passo:**

Vamos representar os dados da turma. Consideraremos uma lista de dicionários, onde cada dicionário representa um aluno e suas notas em diferentes disciplinas.
