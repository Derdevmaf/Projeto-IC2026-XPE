Tarefa: Selecionar os números pares de uma lista em Python. Enunciado: Selecionar apenas os números pares de uma lista de números inteiros. Resolução: Primeiramente, definimos uma lista de números inteiros que contém tanto números pares quanto ímpares. Em seguida, criamos outra lista vazia para armazenar os números pares. Utilizando um loop for, iteramos sobre cada elemento da lista original e verificamos se o número é par utilizando a operação 'modulus' (%). Se o resto da divisão do número por 2 for 0, o número é par e o adicionamos à lista de números pares. Por fim, exibimos a lista de números pares. Observação: Neste exemplo, selecionamos apenas os números pares da lista original para demonstrar como o verbo 'selecionar' pode ser aplicado para filtrar elementos específicos de uma lista com base em critérios definidos.
