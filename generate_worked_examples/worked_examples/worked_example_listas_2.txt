Tarefa: Repetir os elementos de uma lista em Python. Enunciado: Repetir todos os elementos de uma lista de números inteiros. Resolução: Definimos uma lista de números inteiros e, em seguida, utilizamos um loop for para iterar sobre cada elemento da lista. Para cada elemento, imprimimos seu valor. Para repetir o processo, podemos simplesmente chamar o loop for novamente. Exemplo: se tivermos a lista [1, 2, 3], repetir todos os elementos resultaria na saída 1, 2, 3, 1, 2, 3. Observação: Neste exemplo, repetimos os elementos da lista para demonstrar como o verbo 'repetir' pode ser aplicado em operações básicas com listas.
