**Enunciado:**

Em programação Python, existem diferentes maneiras de organizar e armazenar dados em coleções. Explique a ideia principal das estruturas de dados Listas, Tuplas e Dicionários, destacando suas características fundamentais e os cenários típicos em que cada uma seria mais apropriada. O objetivo é dar a ideia central do propósito e funcionamento de cada uma.

**Resolução Comentada:**

Vamos abordar a ideia principal de cada estrutura, passo a passo:

1.  **Ideia Principal Geral:** Em Python, Listas, Tuplas e Dicionários são as ferramentas básicas para agrupar e gerenciar múltiplos valores. A escolha entre elas depende de fatores como a necessidade de ordem, a possibilidade de alteração dos dados após a criação (mutabilidade) e a forma como os dados serão acessados.

2.  **Listas (Lists):**
    *   **Ideia Principal:** Uma lista é uma coleção *ordenada* e *mutável* de itens. Pense nela como uma caixa flexível e extensível onde você pode guardar uma sequência de coisas (números, textos, outros objetos, e até outras listas!), em uma ordem específica. Você pode reorganizar os itens, adicionar novos, remover existentes e modificar qualquer item após a lista ter sido criada.
    *   **Características Fundamentais:**
        *   **Ordenada:** Os itens possuem uma posição (índice), começando do zero. A ordem de inserção é mantida.
        *   **Mutável:** Pode-se adicionar, remover ou modificar itens.
        *   **Heterogênea:** Pode conter itens de diferentes tipos de dados.
    *   **Cenário Típico:** Ideal para armazenar coleções de itens que podem mudar com o tempo, como uma lista de compras, uma fila de tarefas, ou resultados de uma pesquisa onde novos dados podem ser adicionados.

3.  **Tuplas (Tuples):**
    *   **Ideia Principal:** Uma tupla é uma coleção *ordenada* e *imutável* de itens. Ao contrário das listas, uma vez que uma tupla é criada, seu conteúdo (o número de itens e os próprios itens) não pode ser alterado. Imagine-a como um registro fixo de informações.
    *   **Características Fundamentais:**
        *   **Ordenada:** Assim como as listas, os itens têm uma posição e a ordem de inserção é mantida.
        *   **Imutável:** Não é possível adicionar, remover ou modificar itens após a criação.
        *   **Heterogênea:** Pode conter itens de diferentes tipos de dados.
