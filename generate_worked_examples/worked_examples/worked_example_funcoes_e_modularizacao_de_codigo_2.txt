**Passo 1: Completar a definição da função `calcular_area_retangulo`**

A primeira parte do exercício pede para definir a função. Uma função em Python é definida usando a palavra-chave `def`, seguida pelo nome da função e uma lista de parâmetros entre parênteses.

```python
# Definição da função
def calcular_area_retangulo(largura, altura): # Nomes dos parâmetros
    area = largura * altura                 # Cálculo da área usando os parâmetros
    return area                             # Retorna o valor calculado
```
