Enunciado do problema: Desenvolva um algoritmo em Python que organize um conjunto de dados em uma estrutura de dados adequada. Resolução: Primeiro, definimos o conjunto de dados e identificamos a estrutura de dados mais adequada para armazená-los. Em seguida, utilizamos a função dict() para criar um dicionário e organizar os dados. Por fim, imprimimos o dicionário organizado. Exemplo de código: dados = {'nome': 'João', 'idade': 25, 'cidade': 'São Paulo'}; print(dados). Conclusão: O algoritmo desenvolvido organiza o conjunto de dados em uma estrutura de dados adequada, permitindo que os dados sejam facilmente acessados e manipulados.
