Enunciado do problema: Gerar um módulo Python personalizado para realizar operações de strings, incluindo contar o número de ocorrências de uma palavra específica em um texto. Resolução: Passo a passo, começamos criando um novo arquivo Python, por exemplo, 'string_utils.py', e definimos uma função 'contar_ocorrencias' que recebe um texto e uma palavra como parâmetros. Dentro da função, utilizamos o método 'split()' para dividir o texto em uma lista de palavras e então iteramos sobre essa lista para contar as ocorrências da palavra específica. Por fim, retornamos o resultado. Para utilizar esse módulo, simplesmente importamos em outro script Python e chamamos a função com os parâmetros desejados. Conclusão: Ao gerar um módulo personalizado, podemos encapsular funções úteis e reutilizá-las em diferentes projetos Python, aumentando a eficiência e a organização do código.
