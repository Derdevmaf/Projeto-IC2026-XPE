Enunciado do problema: Distinguir entre as estruturas de controle condicionais (if/else) e de repetição (for/while) em Python. Resolução: Para distinguir entre essas estruturas, devemos considerar a função de cada uma. As estruturas condicionais (if/else) são utilizadas para tomar decisões com base em condições específicas, enquanto as estruturas de repetição (for/while) são usadas para executar um bloco de código várias vezes. Por exemplo, se precisamos verificar se um número é par ou ímpar, utilizamos uma estrutura condicional: `if numero % 2 == 0: print('Par') else: print('Ímpar')`. Já para imprimir os números de 1 a 10, utilizamos uma estrutura de repetição: `for i in range(1, 11): print(i)`. Conclusão: É fundamental distinguir entre essas estruturas para usar a ferramenta certa para cada problema.
