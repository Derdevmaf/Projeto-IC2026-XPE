Assinalar as linhas de código que implementam um laço de repetição em Python. Enunciado: Identifique as linhas de código que utilizam laços de repetição no seguinte exemplo: `for i in range(5): print(i)`. Resolução: O laço de repetição está na linha `for i in range(5):`, que é uma estrutura de repetição que itera sobre uma faixa de números de 0 a 4. A função `range(5)` gera uma sequência de números de 0 a 4, e o laço `for` itera sobre essa sequência, executando o código `print(i)` para cada valor de `i`. Conclusão: O laço de repetição é uma ferramenta fundamental em programação, permitindo que se execute um conjunto de instruções várias vezes de forma eficiente.
