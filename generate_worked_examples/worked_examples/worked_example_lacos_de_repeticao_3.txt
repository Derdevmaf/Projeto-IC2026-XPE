Assinalar as diferenças entre as estruturas de repetição `for` e `while` em Python. Enunciado: Identifique as principais diferenças entre as estruturas de repetição `for` e `while` em Python. Resolução: A principal diferença entre `for` e `while` é a forma como a repetição é controlada. O laço `for` é utilizado para iterar sobre uma sequência (como uma lista ou uma faixa de números), enquanto o laço `while` é utilizado para repetir um conjunto de instruções enquanto uma condição específica for verdadeira. Por exemplo, `for i in range(5): print(i)` itera sobre os números de 0 a 4, enquanto `i = 0; while i < 5: print(i); i += 1` também itera sobre os números de 0 a 4, mas utiliza uma variável de controle e uma condição para controlar a repetição. Conclusão: Entender as diferenças entre `for` e `while` é fundamental para escolher a estrutura de repetição mais adequada para cada situação em Python.
