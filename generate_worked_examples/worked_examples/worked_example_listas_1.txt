Tarefa: Criar uma lista de compras para um supermercado utilizando Python. Enunciado: Formular um programa que permita ao usuário adicionar itens à lista de compras e, posteriormente, exibir a lista completa. Resolução: Primeiramente, definimos uma lista vazia para armazenar os itens de compras. Em seguida, criamos um loop para permitir que o usuário adicione itens até que ele decida parar. Para cada item adicionado, utilizamos a função append() para adicionar o item à lista. Por fim, exibimos a lista completa utilizando um loop for. Observação: Neste exemplo, formulamos um programa que permite ao usuário gerenciar uma lista de compras de forma interativa.
