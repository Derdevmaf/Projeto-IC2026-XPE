Enunciado do problema: Caracterizar as características principais da estrutura de controle condicional if/else em Python. Resolução: A estrutura if/else em Python é caracterizada pela sua capacidade de executar diferentes blocos de código com base em condições booleanas. Ela é composta por uma cláusula if que especifica a condição, seguida por um bloco de código a ser executado se a condição for verdadeira. Opcionalmente, pode-se incluir uma cláusula else para especificar o que deve ser feito se a condição não for atendida. Por exemplo: `if hora < 12: print('Bom dia') else: print('Boa tarde ou noite')`. Características importantes incluem a necessidade de indentação para definir os blocos de código e a possibilidade de aninhamento de estruturas if/else. Conclusão: A caracterização da estrutura if/else é essencial para entender como aplicá-la corretamente em programas Python.
