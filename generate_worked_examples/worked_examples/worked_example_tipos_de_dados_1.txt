Exemplo resolvido: Ilustrar a diferença entre tipos de dados numéricos em Python. Tarefa: Explique e ilustre a diferença entre os tipos de dados int, float e complex em Python. Resolução: Em Python, temos três tipos de dados numéricos principais: int, float e complex. O tipo int representa números inteiros, como 1, 2, 3, etc. Já o tipo float representa números de ponto flutuante, como 3.14 ou -0.5. O tipo complex, por sua vez, representa números complexos, que têm uma parte real e uma parte imaginária. Para ilustrar a diferença entre esses tipos, podemos utilizar exemplos: o número 5 é do tipo int, 3.14 é do tipo float e 2 + 3j é do tipo complex. Conclusão: A compreensão dos diferentes tipos de dados numéricos é fundamental em programação, pois cada um tem suas características e utilizações específicas.
