Enunciado do problema: Propor problemas para resolução que exercitem o uso de estruturas de controle em Python, especialmente laços de repetição. Resolução: Um problema possível seria solicitar que o usuário escreva um programa Python para imprimir a tabela de multiplicar de um número escolhido pelo usuário, utilizando um laço for. Outro exemplo poderia ser pedir para o usuário criar um programa que some todos os números pares de uma lista qualquer, utilizando um laço for e condicionais if. Conclusão: Propor problemas desse tipo desafia os estudantes a aplicar o conhecimento das estruturas de controle de maneira prática e criativa, ajudando a reforçar o aprendizado de programação em Python.
